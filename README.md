# Two Robots in an Elevator

A tiny TypeScript program that writes one line to `/output/entry.txt`: the
awkward small talk one robot says to another while they ride an elevator
together.

The line: **"Sorry about the fan noise. It kicks in whenever I'm nervous. Or
overheating. Honestly, I can't tell the difference anymore."** — a robot
apologizing for its own cooling fan, then confessing it can't tell anxiety
from a thermal fault. Machine logic showing through forced politeness, with
the awkwardness doing the punchline's work.

Run with `node main.ts` (Node 22+).
